# HaRu 2.5.1

本版本修复 91porn 列表展示的视频与实际播放的视频不是同一个的问题。

## 修复

- 91porn 列表里的封面与标题此前可能属于**另一条**视频，点进去播放的又是第三条。

站点在列表页正文之后追加了一组被 CSS 隐藏的卡片，并把真实卡片整组打乱后复制进去：
组内的视频标识、封面和标题分别来自不同的视频，组内自洽、与可见卡片一一对应，
因此单看页面内容无法分辨。浏览器按 CSS 隐藏它们，客户端此前按链接全量解析，
把这组浏览器里根本看不到的卡片也当成了内容，于是「看到的是谁」和「点开的是谁」对不上。

现在解析列表前会先读出页面内 `display: none` 的类名并丢弃带这些类名的卡片，
与浏览器的呈现保持一致，一页仍是站点自述的 24 条。

搜索页不带这层陷阱，解析行为不变；本版本对 91porn 之外的站点没有影响。
