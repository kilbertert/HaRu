# HaRu 2.5.0

本版本新增第三个内容源 **91porn**，与 Rule34Video、Hanime 并列成为底部导航的独立一级入口，支持按分类浏览、搜索、直接播放和下载。

## 新增 91porn 内容源

- 底部导航新增 91porn 入口，导航顺序仍可在设置中调整；
- 首页以站点自身的分类作为频道（热门、排行、精华、原创、时长筛选等）；
- 搜索只检索视频，不再显示该站并不存在的标签、艺术家、分类页签；
- 支持直接播放与下载站点提供的免费主源。

## 使用前需要知道的两点

- **该站没有账号体系**，因此不提供登录、收藏、播放列表、订阅和评论；它的下载记录与播放进度通过媒体库的设备级「本机」范围查看；
- **高清是站点的会员限制**，客户端不提供高清选项；免费主源的分辨率由站点随机给出，界面只标注「默认」，不声称具体清晰度。

## 稳定性

- 站点在会话刚建立时会返回**另一个视频**的详情页，且页面自洽、事后无法识别。客户端在取详情前会先建立会话，避免播错视频；
- 站点直链约 15 分钟过期，播放或下载失败时会自动重新获取地址，不需要手动干预。

## 已知抖动

首次播放偶发被站点折回列表页，重试一次即稳定；应用已自动处理该重试。
